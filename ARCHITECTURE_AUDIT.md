Supports 60fps `requestAnimationFrame` playhead clock, multi-track clip rendering, interactive clip move/trim/split/delete, CSS/SVG color grading & shader preview, and live SVG rendering of the 2D Stickman Puppet Rig + 18 move-sets + 12 2.5D camera rigs + 6 procedural stage widgets.

   - **Rust / Tauri Native Core (`apps/desktop/src-tauri/`) is a Non-Functional Stub (`BROKEN` / `EXPERIMENTAL`)**:

## 3. KEY ARCHITECTURAL CONFLICTS & DUPLICATIONS IDENTIFIED

1. **Duplicate Critic / QA Systems**:
   - `services/ai-sidecar/pipelines/vlm_critic_pipeline.py` (`VLMCriticReviewer`) and `services/ai-sidecar/pipelines/ave_director_bridge.py` (`DeterministicCriticReviewer`) both produce QA reports with different field names (`hookRetention`/`pacingAndRhythm` vs. `adherence`/`pacing`/`visualQuality`/`watchability`).
   - **Resolution**: Unify into a single **Visual QA Framework** (`packages/core-schema/src/visual-qa.ts` + Python worker) with deterministic checks first and optional VLM inspection second.
2. **Duplicate MCP Tool Registries**:
   - Tool definitions exist in 3 places: `packages/mcp-bridge/src/tool-registry.ts`, `services/ai-sidecar/mcp_server.py`, and `services/ai-sidecar/mcp_stdio_bridge.py`.
   - **Resolution**: Make the **Command Gateway** and **Video DSL Compiler** the single authoritative contract.
3. **Orphaned Hardware Decoder vs. DOM Media Tags**:
   - `WebCodecsDecoderPool.ts` was created in `apps/desktop/src/components/monitor/`, but `ProgramMonitor.tsx` never imports it, using `<video>` and `<img>` inside `ShaderColorCompositor.tsx`.
   - **Resolution**: Keep a single `MediaPlaybackAdapter` interface in the monitor that uses `<video>`/`<img>` for standard playback and progressively upgrades to WebCodecs frame-accurate scrubbing when supported.
4. **Dual Stickman Renderers (React SVG vs. Python Pillow)**:
   - `StickmanStageRenderer.tsx` renders Stickman scenes in React SVG for interactive 60fps preview, while `scripts/native_stage_renderer.py` renders Stickman scenes in Python `PIL` for headless `.mp4` export.
   - **Resolution**: Both must consume the **exact same `VideoDSL` / `ChoreographedStageScene` & `CharacterDefinition` JSON schema** so preview and native export remain 100% consistent.
